## Content source and rules

Per-concept brief (audience, hero, problem, workflow, value, constraints) is in `plan.md` lines ~74-137. Map: Hero -> `tagline`; Audience -> `spec.audienceValue`; Problem -> `challenge`; Proposed workflow arrows -> `workflow.steps` (one step per arrow segment, merge to max 6); Potential value -> `value.items`; constraint -> phrasing in `solution.body` / `principles` / `nextSteps.body`.

Depth: InvoiceFlow, QuoteFlow = fieldflow length (intro ~3 sentences, bodies ~4 sentences, 4-5 value items, 5 principles). ShiftFlow, StockFlow, FixFlow = shorter (intro 2 sentences, bodies 2-3 sentences, 3-4 value items, 3-4 principles). Every key present in all five.

Wording rules (enforced by acceptance grep, case-insensitive, whole file):
- Never name a system or channel: no WhatsApp, Messenger, SAP, Pohoda, HubSpot, Salesforce. Say "accounting software", "existing systems", "messaging apps" (fieldflow already uses "messaging apps"; that is fine).
- No `%` character, no "saves N", no numbers that imply measured results, no client names, no testimonials.
- Watch substrings: grep `sap` also hits "disappear", "sapling"; avoid those words in both locales (SK: "zasa p" with space is fine, "nesap..." does not exist). Grep `%` means write "percent" nowhere, just avoid the concept.
- Export/integration phrasing: "export for accounting software", "payroll-ready export", "could connect to existing systems in a future phase" — proposed, not existing.
- Every `nextSteps.body` states: concept today, no production deployment, no customer results claimed (mirror fieldflow sentence).
- `meta.title` pattern: `<Name> — <short EN descriptor> Concept | SpexSol`; SK: `<Name> — koncept <descriptor> | SpexSol`.
- SK: natural Slovak, formal, keep product names untranslated (InvoiceFlow etc.). Mirror SK fieldflow tone from `src/i18n/locales/sk/caseStudies.json`.

Categories (field `category`, EN / SK):
- invoiceflow: "Workflow Automation · AI-assisted Document Processing" / "Automatizácia procesov · AI-asistované spracovanie dokumentov"
- quoteflow: "Workflow Automation · Sales Operations" / "Automatizácia procesov · Obchodné procesy"
- shiftflow: "Workflow Automation · Mobile Reporting" / "Automatizácia procesov · Mobilné reportovanie"
- stockflow: "Workflow Automation · Inventory Visibility" / "Automatizácia procesov · Prehľad o zásobách"
- fixflow: "Workflow Automation · Request Coordination" / "Automatizácia procesov · Koordinácia požiadaviek"
