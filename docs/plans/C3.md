# C3 Automation assessment page

**Why:** Brief (plan.md "Conversion page") defines `/automation-assessment` with H1 "What could we automate in your business?". Today concept visitors only have generic `/contact`. Reuse existing validated form + Slack delivery; only preselect topic `automation` and add page copy. No new fields, schema, backend or nav.

## Model
No data or backend change. One prop added to two components:

```ts
// src/components/site/ContactForm.tsx
export function ContactForm({ defaultTopic = 'product' }: { defaultTopic?: ContactTopic })
// src/components/site/ContactSection.tsx
export function ContactSection({ showTitle = true, defaultTopic }: { showTitle?: boolean; defaultTopic?: ContactTopic })
```

`ContactTopic` already exported from `src/lib/contact-schema.ts`; `'automation'` already in `CONTACT_TOPICS` and labelled in `home.json` (`contact.topics.automation`, EN "Automation", SK "Automatizácia").

## Screens / Routes
`/$lang/automation-assessment`: same layout as `/$lang/contact` (`max-w-6xl` wrapper, `PageHeader`, `ContactSection showTitle={false}`). Difference: `PageHeader` reads `contact:assessment.pageTitle` / `assessment.pageSubtitle`; topic radiogroup and mobile select show "Automation" selected on load. After successful submit form resets and topic returns to `automation` (not `product`). Loading, error, success, honeypot, privacy checkbox: unchanged (owned by `ContactForm`).

`/$lang/contact`: no visible change; `defaultTopic` omitted → `'product'`.

## Pure helpers
None. No branch or parsing added; one default prop value.
