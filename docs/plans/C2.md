**Why:** `/$lang/case-studies` index has a generic "Case studies" title and subtitle. Brief (plan.md, "`/solutions` landing page") wants problem-first positioning, an explicit concept disclosure and a contact CTA so the index works as the Solutions landing. No new route: the existing index page gets the copy and CTA.
