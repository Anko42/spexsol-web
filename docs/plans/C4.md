# C4 Homepage work section cap and concept framing

**Why:** Home "Products & case studies" section renders every case study. After C1 lands six concept case studies, the section pushes Offer and FAQ below the fold and verified products lose prominence. Cap the list at 3 case studies (products always shown first) and add a one-line subtitle making clear case studies are solution concepts, not delivered client work.

No data or type changes. `caseStudies` in `src/data/case-studies.ts` keeps its current array order; the home route takes the first 3. No ordering logic in the data file (task non-goal).

- "All case studies" link unchanged.
- Section visibility guard `(products.length > 0 || caseStudies.length > 0)` unchanged.
- No empty/loading/error states: data is static.
